## 좌표와 단위 — 가장 많이 틀리는 곳

- **S4 정렬 이후 모든 좌표는 TRELLIS 정규화 공간이다. 신장이 약 1.0 이고 미터가 아니다.**
  0.028, 0.08 같은 수치에 "m" 을 붙이지 않는다.
- **정렬 스케일(약 0.589)은 SMPL 메쉬에만 곱해진다.** `scale = TRELLIS 높이 / SMPL 높이`.
  TRELLIS 메쉬는 측정만 되고 변하지 않는다.
- 이 값이 여러 샘플에서 비슷하게 나오는 것은 **정규화의 결과**다. 정렬 정확도의 근거로 쓰지 말 것 —
  역할은 **이상 탐지**다(벗어나면 메쉬 잘림·부유 지오메트리·체형 추정 이상).
- **FBX 는 정규화 크기로 나가고 Unity 에서 수동 보정 중이다.** export 에서 미터를 복원하기로
  정했으나(`global_scale = 1/정렬스케일`, 약 1.70) **구현은 M2 E2E 이후**다.

## 리깅과 동작

- **리그의 rest pose 는 T포즈가 아니라 키프레임 자세다.** 그래서 Unity 는 **Generic 리그**를 쓴다.
  Humanoid 로 두면 근육 변환에서 동작이 왜곡된다. T포즈 rest 리그 재생성은 EH-211.
- **WHAM pose 는 기준 프레임(`--frame`, 기본 3) 대비 상대 회전으로 적용된다.**
  "변환 없이" 는 **골격 간 변환(리타게팅)이 없다**는 뜻이지 회전 계산이 없다는 뜻이 아니다.
- `--frame` 은 TRELLIS 에 넣은 키프레임과 **같은 번호**여야 한다.
- **관절-메쉬 거리(0.028)는 SMPL_body 기준**이고 관절 좌표의 축 보정을 판정하는 값이다.
  뼈가 TRELLIS 메쉬 안에 있는지는 보장하지 않는다 — 그 직접 지표는 아직 없다(G2r 후보).
- **리깅 본류의 체형 = WHAM 프레임 f 정점.** 평균 betas 경로(`smpl_tpose.obj`,
  `joints["tpose"]`)는 현재 **미소비**이며, 제거하지 않고 EH-211 의 입력 후보로 남긴다.

## 웨이트 전이

**3단이다.** 1차 직접 93.2% / 2차 BFS 전파 5.3% / 3차 직선거리 폴백 1.5% = 100%, 무배정 0%
(512 기준, 정점 671,643). 품질 서열은 1차 > BFS > 폴백이라 폴백만 따로 추적한다.
1차와 폴백만 적어 94.7% 로 쓰는 것은 단계 누락이다.

`max-dist 0.08` 의 **선정 근거는 기록돼 있지 않다.** 0.05/0.08/0.12 비교 실험이 M2 이후 백로그.
